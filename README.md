A small program that writes one single-line one-star review (131 characters) to `/output/entry.txt`: a house cat reviewing its human — the human watches other cats on a glowing rectangle all day, then acts shocked when the reviewer sits on it. The reviewer lives here. The screen cats do not.

## Run it

```sh
node main.ts
cat /output/entry.txt
```

No network, no model calls, deterministic output.
